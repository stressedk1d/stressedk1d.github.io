Сжатие панорам Panorama

17 equirectangular-панорам для Panolens весили ~510 MB — GitHub Pages такое не переваривает. Нужно было сжать без полной потери качества на экране.

Написал скрипт compress_panoramas.py на Pillow: resize + JPEG quality, пакетная обработка папки PANORAMA/images.

  • Было: ~510 MB, стало: ~10 MB
  • Удалены дубликаты PANORAMA/images (~500 MB)
  • Обновлён preview для карточки на главной

Итог: демо грузится за секунды, а не минуты. Для портфолио это критично — никто не ждёт 500 MB на мобилке.
