AI-поиск в Vogue Way

Vogue Way — дипломный маркетплейс модной одежды. Одна из фишек — поиск товара по фото: загружаешь картинку, получаешь похожие позиции из каталога.

Backend на FastAPI, модель CLIP. При первом запросе к /ai/search модель подгружается lazy — это экономит память при старте API.

  1. Пользователь загружает фото
  2. CLIP строит эмбеддинг изображения
  3. Cosine similarity с эмбеддингами каталога
  4. Топ-N товаров в ответе API

Первый запрос медленный (загрузка модели), дальше — быстрее. Демо: vogueway.ru
