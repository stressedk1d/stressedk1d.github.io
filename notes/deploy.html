Как я деплою портфолио

Сайт живёт на GitHub Pages в репозитории stressedk1d.github.io. Локально исходники лежат в папке My_web_site, а деплой идёт двумя способами.

deploy.ps1 — копирует файлы в _deploy (клон репозитория), генерирует og-image через Python и пушит в main.

  • generate_assets.py — og-image.png, og-image.gif и PWA-иконки
  • Копирование fonts, images, projects, panorama, notes
  • git push origin main

GitHub Actions — workflow deploy-site.yml собирает bundle на push и деплоит через GitHub Pages artifact. Удобно, если пушишь прямо в репозиторий сайта.
